## What's new in 0.10.1

### Typing while Nacho answers no longer stops the answer
- Before, pressing Enter or the send button while Nacho was still answering stopped the answer, and what you had
  typed stayed in the input box.
- Now, when you have typed something, the button shows **보내기** instead of stop. Enter or **보내기** keeps the answer
  going and puts your message in the chat as waiting, with **답이 끝나면 보낼게요 · 취소**. The input box is cleared.
- When the answer ends, whether it finished, failed or was stopped, the waiting message is sent once by itself.
  Files waiting under the input box go with it.
- **취소** drops the waiting message. Sending again while one is waiting adds the new text to it on a new line.
- If the waiting message cannot be sent (for example, the connection dropped), it goes back into the input box with
  a note, so nothing you typed is lost.
- With an empty input box the button is still **멈추기** and stops the answer. Enter never stops an answer.

### Nacho's answers show bold text
- `**굵게**` in Nacho's answers is shown in bold instead of with the stars; `*기울임*` and `` `코드` `` are shown as
  italic and code, and line breaks stay as written. What you type is shown exactly as you typed it.
- Links in Nacho's answers can be clicked only when they are web (http, https) or mail links. Any other link is shown
  as plain text.

### Full status in the header
- When the status line in the chat header is cut off, hover over it to see the whole text.

Your settings stay as they were.

**Not yet tried on a real Mac.** Sending while Nacho answers, the waiting message, bold text and the header tooltip
were checked with tests and off-screen renders in CI only. Pressing Enter while composing Korean, and real answer
timing from the server, have not been checked on a Mac.
