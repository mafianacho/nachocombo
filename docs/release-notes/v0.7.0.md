## What's new in 0.7.0

- **A widget board.** Every tool is now a widget on one board (the main window), in light and dark as the system is
  set. Each widget has a status circle (gray off, green on, green with a yellow half behind it when it is on but needs
  more setup, red on an error; the words are in its tooltip and for VoiceOver), its name, its open shortcut if you set
  one, and an ON/OFF switch that works while the widget is off. An off widget fades only its body.
  Widgets show what their tool really reports, for example:
  - System Monitor: CPU, memory and startup disk rings, network down/up;
  - Computer Use: Accessibility and Screen Recording, with a button for the missing one;
  - Keep Awake: the time left of a timed hold, as a ring;
  - Clipboard History: the latest copies as the history list shows them;
  - Device Control: volume, an external display's brightness, the output;
  - Calendar Clock: today and the next event (with Calendars access);
  - Disk Map: used of total, and the top folders once you have mapped the disk;
  - File Shelf, Capture Float, Focus Dim, Window Snap, Mouse Tune, Nacho Pet (sign in from the widget).

  Menu Bar and App Switch stay simple widgets: macOS gives no list of other apps' menu bar icons, and there is no
  recent-apps list to show.
- **Edit mode.** **위젯 편집** lets you drag widgets around, hide one with **−**, and pick its size (작게 / 가로 / 크게)
  in the panel on the right, where you also pin it to the menu bar, see its shortcut and hide it. With the keyboard:
  select a widget, move it with the arrow keys, hide it with Delete. **완료** or Esc ends edit mode. The order, sizes
  and hidden widgets are kept. With **Reduce motion** on, widgets do not wiggle in edit mode.
- **Mini board in the menu bar.** A click on the nacho box opens the widgets you pinned, small. **＋ 위젯 고정** pins
  one more, **전체 도구 열기 ›** opens the board. Pinning never switches a tool on or asks for a permission; pinned
  tools keep their own menu bar icon that opens their controls.

Your settings stay as they were (tools on, pins, shortcuts, pet). The first board puts Nacho Pet and the tools that are
on first.

**Signing in to the production server** works once the server side has the Nacho Combo login client set up. Until
then, signing in to production does not complete; everything else works as before.

**Not yet tried on a real Mac.** The board's logic is covered by tests on Linux and macOS, and its AppKit views were
drawn off screen on the macOS CI machine to compare them with the design. The app itself has not been run on a Mac
with this version.
