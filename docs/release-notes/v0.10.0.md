## What's new in 0.10.0

### Nacho can quit an app — after you say yes
- Ask "메모 앱 종료해 줘" and Nacho first shows an approval card: "메모 앱을 종료할까요?" with **실행** / **거절**.
  Nothing happens until you answer.
- **실행** asks the app to quit the normal way, so it can still ask to save. Nacho never force-quits, and Finder and
  Nacho Combo itself are never quit. **거절** leaves the app as it is.
- Like Nacho's other actions on this Mac, it only works while **Let Nacho use apps, windows and gadgets on this Mac**
  is on. The note under that switch now says so instead of "Nacho never quits apps".

### Allow it from now on
- When the server offers rules on an approval card, the card lists them: **1 이번만 실행**, then one
  **실행하고 항상 허용** row per rule with the rule in one line (for example "하루 30,000원까지 묻지 않고 결제"),
  then **거절**.
- Pick a row with its number key + Enter or a click. The rule you chose is saved on the server, and the same request
  within that rule runs without asking next time. Once answered, the card marks the row you chose.
- Rules are never set by voice: payments still cannot be approved by speaking.
- Cards without rules look and work as before.

Your settings stay as they were.

**Not yet tried on a real Mac.** Quitting a real app, and a saved rule letting the next request through, were checked
with off-screen renders and tests in CI only.
