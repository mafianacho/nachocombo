## What's new in 0.6.0

- **Nacho Pet talks to Nacho (nacho-server).** In the chat you see:
  - the room's earlier talk, including messages from your phone, with **이전 대화 더 보기** for older ones;
  - what Nacho is doing on the way: tool lines in Korean (웹 검색, 페이지 읽기, 창 배치…) and short "still working" lines;
  - tasks that Nacho takes on and finishes later;
  - choice questions you can answer in the pet (approvals for payments, calls and the like stay on the phone app);
  - files Nacho made, as links;
  - memory lines: what it remembered (**잊어 줘**, then **N초 안에 되돌리기**) and the memories an answer used
    (**기억이 틀렸어요**);
  - credit and light-chat usage (read only);
  - maintenance notices and the server's error messages in Korean.

  Pictures and files go up the server's upload path. Dictation uses the server when it offers it, and the Mac's own
  speech recognition otherwise.
- **New pet screens.** The chat bubble was redrawn from a reviewed design, in light and dark:
  - a tail pointing at Nacho;
  - one status line in the header;
  - speech bubbles that wrap Korean between words;
  - cards with option buttons;
  - file chips;
  - example requests on the first screen;
  - a rounded input field with a send/stop button.

  Hovering over Nacho shows a name tag. Dragging a file over it shows a drop ring.
- **Nacho moves.** It moves using only the original Nacho pictures:
  - a soft crossfade between states;
  - breathing and random blinks while idle;
  - its own small loop while listening, thinking and answering;
  - a little hop when an answer is done;
  - dozing off after a long quiet time;
  - a press, a lean while you drag it, and a landing when you let go.

  **Reduce motion** in System Settings keeps only the crossfade. Nacho stops moving (and uses no CPU for it) while it
  is covered, the displays sleep, or a full-screen app is in front.

**Signing in to the production server** works once the server side has the Nacho Combo login client set up. Until
then, signing in to production does not complete; everything else in Nacho Combo works as before.

**Not yet tried on a real Mac.** The pet's logic is covered by tests on Linux and on macOS in CI, and the screens were
checked as a web mockup in a browser. The app itself has not been run on a Mac with this version.
