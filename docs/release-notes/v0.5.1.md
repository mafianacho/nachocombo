## What's new in 0.5.1

- **Automatic updates.** Nacho Combo now downloads a new version in the background, checks it (the release's
  `SHA256SUMS.txt`, bundle id, version and code signature) and installs it **when you quit** (also at logout or
  restart); if that did not happen, the next launch installs it first. It never restarts by itself while you use it.
  **Restart to Update** in the menu bar menu installs at once. General ▸ Updates ▸ **Install Automatically** (on by
  default) turns this off; then nothing is installed until you click Update…. New versions are looked for at launch and
  every 6 hours.
- **Few files.** At most two copies are kept on your Mac: the version waiting to be installed and the one before the
  running version. Older copies, zips and interrupted downloads are deleted at once.
- **Go back any time.** General ▸ Updates ▸ **Revert to x.y.z…** puts the previous version back; automatic updates do
  not install the version you left again (a newer one still comes). Every version stays on the
  [Releases page](https://github.com/mafianacho/nachocombo/releases).
- **Automatic recovery.** If a new version fails to start properly twice in a row, the next launch goes back to the
  previous version by itself.
- **Permissions after an update.** Nacho Combo is ad-hoc signed, so macOS may ask again for Accessibility or Screen
  Recording after an update. The first launch after an update lists the gadgets that lost their permission and opens
  the Permissions page.

**Coming from 0.5.0:** 0.5.0 has the old updater, so install this version **once by clicking Update…** (General ▸
Updates or the menu bar menu). From 0.5.1 on, updates are automatic.

**Not yet tried on a real Mac.** The update engine was tested end to end against mock releases, on macOS in CI with real
`ditto` and `codesign`, but this version has not been run on a Mac. Limit: the automatic recovery runs inside the new
version, so a version that crashes before any of its code runs cannot go back by itself; download an older version from
the Releases page then.
