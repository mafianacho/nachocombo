## What's new in 0.4.0

- **Computer Use (experimental).** A new gadget: an MCP (Model Context Protocol) server through which a client that holds a
  key you made can see and control this Mac. **Not yet tried on a real Mac.** It is **off by default**, every tool group
  starts off, high-risk tools (AppleScript, shell, file access, force quit) ask before they turn on, and ⌃⌥⌘. stops every call at once.
  It listens on 127.0.0.1 only; the optional **LAN mode needs TLS (a pinned self-signed certificate) and a key** and only
  accepts private addresses. Combos never switch it on. Details and the list of what is unverified:
  [docs/COMPUTER-USE-MCP.md](https://github.com/mafianacho/nachocombo/blob/v0.4.0/docs/COMPUTER-USE-MCP.md).
- **In-app updates.** General ▸ Updates looks for a new release on GitHub at launch and once a day (you can turn that
  off) or when you press Check Now. Nothing is installed until you click Update: the zip is checked against
  `SHA256SUMS.txt` and its code signature, then replaces the app in one step (the old copy goes to the Trash) and Nacho
  Combo restarts. The update path is also **not yet tried on a real Mac**.

**Coming from 0.3.0 or earlier:** those versions cannot update themselves. Download this version once by hand (below);
later versions can then be installed from inside the app. After an update macOS may ask again for Screen Recording and
Accessibility, because the app is ad-hoc signed.
