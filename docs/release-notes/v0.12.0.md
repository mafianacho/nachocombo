## What's new in 0.12.0

_This version has no new pictures: the only change is the login address, and the login page is a web page outside the app. The app's screens are in Korean; button names are given in Korean with an English gloss._

### Login now uses the unified Nacho account
Nacho Pet's login moves to the unified Nacho account at `auth.mafianacho.com`. The old login server (`auth.nachotown.com`) is no longer used by this version.

1. Update Nacho Combo and open it. The What's new window explains the change.
2. Log in from Nacho Pet again; your browser opens the new login page. You have to log in once more after this update.
3. Verify your phone number on that page. This creates your new Nacho account.

### Your old account and data do not carry over
The new account is a new account. Your earlier Nacho account, its chats, memories and other data are **not linked** to it and do not move over. The earlier account's data stays on the old side.

Your Nacho Combo settings and gadgets stay as they were.

## Not yet tried on a real Mac
The login change was checked with tests and the mock server in CI, and the production login page was checked to accept this app's sign-in return address. It has **not** been tried on a real Mac: opening the new login page from Nacho Pet, the phone number verification, the return to the app from the browser, and the update from 0.11.0 itself (automatic install and relaunch). Pictures are not included for this reason.

The app is still ad-hoc signed, so macOS may ask for the Keychain password once.
